# BND008: Schema プロパティは partial 定義である必要があります

> プロパティ '{0}' は public な getter を持ち、アクセサー本体を持たない public インスタンス partial プロパティ定義である必要があります。この ViewModel のソースは生成されません。

## 原因と修正方法

`[ViewModel]` 型の `[Schema]` プロパティは、public な getter を持つ public インスタンス partial プロパティとして定義します。Generator が C# 14 の `field` キーワードを使った実装を生成します。

```csharp
// Invalid: an ordinary auto-property.
[Schema("TMPro.TMP_Text.text")]
public int Count { get; set; }

// Correct: a partial definition without accessor bodies.
[Schema("TMPro.TMP_Text.text")]
public partial int Count { get; set; }
```

getter のみの定義と、アクセス制限を含む `set` / `init` に対応します。static・abstract・extern・ref 戻り値・インデクサー・非 public プロパティ／getter・手書きのアクセサー本体には対応しません。メソッドへの Schema は引き続き有効です。フィールドへの付与は `AttributeUsage` に基づいてコンパイラーが拒否します。

## 対象範囲と生成の継続

Source Generator は ViewModel 属性のあるクラス・構造体の Schema プロパティを検査します。入力に含まれる生成コードも対象ですが、自身が出力した実装は検査しません。Schema のないプロパティと ViewModel 属性のない型は対象外です。不正なプロパティがある場合、その型の ViewModel と View の生成を中止します。他の ViewModel の生成は継続します。
