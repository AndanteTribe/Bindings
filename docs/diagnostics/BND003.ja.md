# BND003: 同じ View フィールドのツールチップが競合しています

[English](BND003.md) | 日本語

| 項目 | 内容 |

| 標準重大度 | Error |
| 既定で有効 | はい |

## メッセージ

> 同じ id を持つ複数の [Schema] により、View フィールド '{0}' のツールチップが競合しています。最初のツールチップのみが使用されます。

`{0}` は生成するコンポーネントフィールド名です。

## 原因

同じViewコンポーネントフィールドを共有するSchemaエントリに、異なる非空のtooltipが指定されています。共有する条件は、コンポーネント型と非負のIDが両方同じであることです。

## 違反例

```csharp
[Schema(PathResolver.UnityEngine.UI.Button.onClick, id: 0, tooltip: "Accept")]
public void Accept() { }

[Schema(PathResolver.UnityEngine.UI.Button.onClick, id: 0, tooltip: "Confirm")]
public void Confirm() { }
```

両メソッドは `_acceptButton` を使用しますが、tooltipが一致していません。

## 修正例

共有するtooltipを1か所だけに指定するか、すべてのエントリで完全に同じ文字列にします。

```csharp
[Schema(PathResolver.UnityEngine.UI.Button.onClick, id: 0, tooltip: "Accept and confirm")]
public void Accept() { }

[Schema(PathResolver.UnityEngine.UI.Button.onClick, id: 0)]
public void Confirm() { }
```

別々のコンポーネントを意図している場合は、異なるIDにするか、両方のIDを省略します。

## 選択規則とソース生成

- 最初の非空tooltipを採用します。フィールドを先に、次にメソッドを、それぞれ宣言順で収集します。
- 空のtooltipは競合しません。同じ非空文字列同士も競合しません。
- `id = -1` のエントリは独立するため、互いのtooltipは競合しません。
- コンポーネントフィールドの `SerializeField` より前に、Unityの `Tooltip` 属性を生成します。
- 競合するViewフィールドごとに、ソース位置なしで1回報告します。最初の非空値を使って両方のソースの生成を継続しますが、既定の重大度はErrorのため、コンパイルは失敗します。
