## メッセージ

> 型 '{0}' のアクセシビリティ '{1}' はサポートされていません。ViewModel '{2}' のソースは生成されません。

`{0}` は対応できない型、`{1}` はRoslynのアクセシビリティ、`{2}` は影響を受けるViewModelです。

## 原因

`[ViewModel]` 型、またはその親型の宣言済みアクセシビリティを生成コードで表現できません。ViewModelとViewを生成するときに、これらの型宣言を再現する必要があります。

| Roslynのアクセシビリティ | 生成するキーワード |
| --- | --- |
| `Private` | `private` |
| `ProtectedAndInternal` | `private protected` |
| `Protected` | `protected` |
| `Internal` | `internal` |
| `ProtectedOrInternal` | `protected internal` |
| `Public` | `public` |

`NotApplicable` および未知の値には対応していません。この診断は、想定外のシンボルやエラーシンボルへの防御も兼ねています。

## 修正方法

メッセージ中の型とC#コンパイラーのエラーを確認し、上表で表現できる正しい宣言にしてください。例えば次のネスト型は対応しています。

```csharp
public partial class Screen
{
    [ViewModel]
    private partial class CounterViewModel { }
}
```

生成される `CounterView` も `Screen` 内のprivateな型になります。親型はすべてpartialである必要がありますが、`partial` 不足はBND004の条件ではなく、別のC#コンパイルエラーです。同様に、トップレベルでは不正なアクセシビリティでも、Roslynが対応可能な値を返す場合はコンパイラーの診断に委ねます。

## ソース生成

取得できる場合は、対応できない型のソース位置に報告します。対象ViewModelについては両方のソースを生成しません。他のViewModelの生成は継続できます。ジェネレーター全体を例外で停止させず、問題を診断として報告します。
