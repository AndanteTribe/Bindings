# BND008: Schema properties must be partial definitions

> Property '{0}' must be a public instance partial property definition with a public getter and no accessor bodies. No source will be generated for this ViewModel.

## Cause and fix

`[Schema]` properties in a `[ViewModel]` type must declare a public instance partial property with a public getter. The generator supplies the implementation using C# 14's `field` keyword.

```csharp
// Invalid: an ordinary auto-property.
[Schema("TMPro.TMP_Text.text")]
public int Count { get; set; }

// Correct: a partial definition without accessor bodies.
[Schema("TMPro.TMP_Text.text")]
public partial int Count { get; set; }
```

Getter-only definitions and `set` / `init` accessors (including restricted setter accessibility) are supported. Static, abstract, extern, ref-returning properties, indexers, non-public properties/getters, and user-written accessor bodies are not supported. Methods remain valid Schema targets; fields are rejected by the compiler through `AttributeUsage`.

## Scope and generation

The source generator checks Schema properties in attributed ViewModel classes and structs, including generated input syntax; it does not inspect its own emitted implementations. Properties without Schema and types without ViewModel are excluded. An invalid property stops both ViewModel and View generation for that type only. Other ViewModels continue generating.
