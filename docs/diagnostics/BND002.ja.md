# BND002: [Schema] の id 値が無効です

[English](BND002.md) | 日本語

| 項目 | 内容 |
| --- | --- |
| カテゴリ | Bindings |
| 標準重大度 | Error |
| 既定で有効 | はい |
| Code Fix | なし |

## メッセージ

> [Schema] の id 値 {0} は無効です。明示的にグループ化する場合は 0 以上を指定し、自動採番する場合は id を省略してください（既定値は -1）。

`{0}` は不正なIDです。

## 原因

フィールド・メソッドの `[Schema]` に、`-1` 未満の `id` が指定されています。

## 違反例

```csharp
[Schema(PathResolver.UnityEngine.UI.Button.onClick, id: -2)]
public void Submit() { }
```

## 修正例

独立したコンポーネントには `id` を省略し、共有する場合は0以上のIDを指定します。

```csharp
[Schema(PathResolver.UnityEngine.UI.Button.onClick)]
public void Submit() { }

[Schema(PathResolver.UnityEngine.UI.Button.onClick, id: 0)]
public void Accept() { }

[Schema(PathResolver.UnityEngine.UI.Button.onClick, id: 0)]
public void Confirm() { }
```

この例では `Accept` と `Confirm` が1つのButtonを共有し、`Submit` は別のButtonを使用します。

## コンポーネント共有

- 同じコンポーネント型かつ同じ非負IDの場合に共有します。IDが同じでも、型が異なれば共有しません。
- `id = -1` は各エントリが独立します。同一メンバーに属性を複数付けた場合も同様です。省略は `-1` と同じ意味です。
- IDを生成フィールド名の末尾へ直接付加するわけではありません。[コンポーネントフィールドと共有](../../README_JA.md#コンポーネントフィールドと共有)を参照してください。

## ソース生成

不正な属性ごとに診断を報告し、連鎖的なエラーを避けるため、そのIDを `-1` として処理します。他の診断によって中止されない限り、両方のソースを生成します。ただし、既定の重大度はErrorのため、コンパイルは失敗します。
