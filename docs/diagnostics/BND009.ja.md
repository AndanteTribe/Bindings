# BND009: Schema プロパティのシリアライズ属性は自動生成されます

[English](BND009.md) | [README に戻る](../../README_JA.md#アナライザー診断)

| 項目 | 値 |
| --- | --- |
| カテゴリ | Bindings |
| 標準重大度 | Error |
| 既定で有効 | はい |
| Code Fix | なし |

> Schema プロパティ '{0}' から SerializeField を削除してください。Bindings が Editor 限定のシリアライズ属性を生成します。この ViewModel のソースは生成されません。

## 原因

Schema プロパティのユーザー宣言に `UnityEngine.SerializeField` が付与されています。この属性は Editor のデバッグ表示用として Bindings が生成します。

## 違反例

```csharp
[field: UnityEngine.SerializeField]
[Schema("TMPro.TMP_Text.text")]
public partial int Count { get; set; }
```

## 修正例

ユーザー宣言から `SerializeField` を削除します。

```csharp
[Schema("TMPro.TMP_Text.text")]
public partial int Count { get; set; }
```

生成実装には `#if UNITY_EDITOR` 限定で `[field: global::UnityEngine.SerializeField]` が付きます。

## 対象範囲と生成への影響

Source Generator は ViewModel クラス・構造体の対応可能な Schema プロパティ定義を検査します。`field:`・`property:`、別名や完全修飾名での指定も対象です。他の生成処理による入力構文も対象ですが、自身の生成実装は検査しません。Schema のないプロパティ、ViewModel でない型、無関係な属性は対象外です。未対応の定義は先に BND008 として報告されます。違反時は該当する型の ViewModel と View の生成だけを中止し、他の ViewModel の生成は継続します。
