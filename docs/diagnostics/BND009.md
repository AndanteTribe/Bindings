# BND009: Schema property serialization is generated

[日本語](BND009.ja.md) | [Back to README](../../README.md#analyzer-diagnostics)

| Property | Value |
| --- | --- |
| Category | Bindings |
| Default severity | Error |
| Enabled by default | Yes |
| Code fix | None |

> Remove SerializeField from Schema property '{0}'. Bindings generates its Editor-only serialization attribute. No source will be generated for this ViewModel.

## Cause

The user declaration of a Schema property has `UnityEngine.SerializeField`. Bindings generates this attribute for Editor debug inspection.

## Violation

```csharp
[field: UnityEngine.SerializeField]
[Schema("TMPro.TMP_Text.text")]
public partial int Count { get; set; }
```

## Fix

Remove `SerializeField` from the user declaration.

```csharp
[Schema("TMPro.TMP_Text.text")]
public partial int Count { get; set; }
```

The generated implementation receives `[field: global::UnityEngine.SerializeField]` under `#if UNITY_EDITOR`.

## Scope and generation

The source generator checks supported Schema property definitions in ViewModel classes and structs, including generated input syntax. `field:` and `property:` targets, aliases, and fully-qualified names are included. It does not inspect its own emitted implementations. Properties without Schema, types without ViewModel, and unrelated attributes are excluded. Unsupported definitions are reported as BND008 first. A violation stops ViewModel and View generation for that type only; other ViewModels continue generating.
