# BND007: Schema フィールドには生成されたプロパティを通じてアクセスしてください

[English](BND007.md) | 日本語

| 項目 | 内容 |
| --- | --- |
| カテゴリ | Bindings |
| 標準重大度 | Error |
| 既定で有効 | はい |

## メッセージ

> フィールド '{0}' には [Schema] が付与されています。フィールドではなく、生成されたプロパティ '{1}' にアクセスしてください。

`{0}` はSchemaフィールド、`{1}` は生成プロパティ名です。

## 原因

`[ViewModel]` を直接付与した型で宣言された `[Schema]` フィールドを、ユーザーコードが直接参照しています。生成プロパティのsetterは再バインドを通知しますが、フィールドへの直接書き込みはそれを経由しません。読み取り時も生成プロパティを使用します。

## 違反例

```csharp
[ViewModel]
public partial class CounterViewModel
{
    [Schema(PathResolver.TMPro.TMP_Text.text)]
    private int _count;

    public void Increment() => _count++;
}
```

## 修正例

生成プロパティを使用します。

```csharp
public void Increment() => Count++;
```

プロパティ名は、先頭のアンダースコアを除去し、続く `m_` を除去したあと、先頭を大文字化します。`_count`・`__count`・`m_count` はいずれも `Count` です。[生成コードの規則](../../README_JA.md#生成コードの規則)を参照してください。

## 対象範囲と例外

- フィールドのアクセシビリティにかかわらず、読み取り・代入・複合代入・増減・`ref`/`out`/`in` 引数・refローカルを検査します。
- コンストラクター・ユーザー定義アクセサー・ラムダ・ローカル関数・ネスト型・partial宣言・アクセス可能なフィールドへの外部参照も含みます。
- フィールド参照式ごとに1回報告します。ViewModel属性を直接付与した型で宣言されたフィールドだけが対象です。Schemaメソッド・属性のないフィールド・ViewModel以外のSchemaフィールドは対象外です。
- 生成されたgetter/setterを含む生成コードは対象外です。`nameof(_count)` は値を読み書きしないため許可します。
- `private int _count = 1;` のような宣言時初期化は許可します。ただし、初期化式の中にある他のSchemaフィールドへの参照は検査します。

## 単純置換できないアクセスの修正

自動Code Fixはありません。通常のプロパティでは、すべてのフィールド参照を直接置換できません。`ref`/`out` 操作や構造体フィールドのメンバー変更では、適切なローカル変数を経由し、必要に応じて最終値をプロパティへ代入します。元の処理の意味を維持してください。

生成setterの後に重複して手動通知する必要はありません。構築中にsetterを呼ぶ場合はPublisherを先に初期化します。クラスだけに生成される `OnPostConstruct` は、RequiredメンバーとPublisherの代入後に呼び出されます。

## ソース生成

推奨するプロパティを利用できるよう、ソース生成は継続します。修正にコードの組み替えが必要な場合も、重大度はErrorのままです。
