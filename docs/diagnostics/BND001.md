# BND001: ViewModel type name must end with "ViewModel"

English | [日本語](BND001.ja.md)

| Property | Value |
| --- | --- |
| Category | Bindings |
| Default severity | Error |
| Enabled by default | Yes |
| Code fix | None |

## Message

> Type '{0}' is annotated with [ViewModel] but its name does not end with "ViewModel". No source will be generated for this ViewModel.

`{0}` is the annotated type name.

## Cause

A class or struct annotated with `[ViewModel]` has a name that does not end with the case-sensitive suffix `ViewModel`. The generator derives the View name by replacing only that suffix with `View`.

## Violation

```csharp
[ViewModel]
public partial class Counter { }
```

## Fix

End the type name with `ViewModel`:

```csharp
[ViewModel]
public partial class CounterViewModel { }
```

This produces `CounterView`. Update references to the renamed type as needed.

## Scope and generation

The diagnostic is reported at the annotated type declaration. Neither its ViewModel source nor its View source is generated. Other ViewModels can still be generated. This rule is reported by the source generator, rather than the usage analyzer.

See [generated-code conventions](../../README.md#generated-code-conventions) for containing types and generated file names.
