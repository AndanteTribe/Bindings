# BNDP001: Use the generated self-rebind helper

## Message

> Use PublishRebindMessage() instead of directly publishing a rebind message for '{0}'

`{0}` is the current ViewModel type.

## Cause

A `[ViewModel]` directly publishes a rebind for its own exact type through its own `_publisher` field, when an equivalent parameterless `PublishRebindMessage()` helper exists. Prefer the helper to avoid repeating the type argument.

## Violation

```csharp
[ViewModel]
public partial class CounterViewModel
{
    public void Refresh() => _publisher.PublishRebindMessage<CounterViewModel>();
}
```

## Fix

```csharp
public void Refresh() => PublishRebindMessage();
```

The helper is generated by Bindings. A generated Schema setter already calls it; do not add a redundant notification after such a setter.

## Scope and exceptions

- The target must be the parameterless generic `Bindings.IMvvmPublisher.PublishRebindMessage<T>()` returning void, with `T` equal to the current ViewModel type.
- The receiver must be that instance's non-static `_publisher` field, declared on the same type and typed as `IMvvmPublisher`.
- Calls through locals, properties, other instances, conditional access, explicit receiver conversions, other publishers, or other type arguments are excluded. Invocations containing preprocessor directives are excluded.
- An unambiguous parameterless non-generic instance helper returning void must exist. Its complete body must be a single equivalent self-rebind call, either expression-bodied or a single expression statement. A missing or behaviorally different helper is not suggested.
- The helper itself is excluded by symbol identity, so it is not replaced with a recursive call.
- Generated code is analyzed and reported under the same conditions as handwritten code. File names or generated-code markers are not exemptions. Actual framework symbols are required.

## Code Fix

An explicit IDE action replaces the invocation with `PublishRebindMessage()`, or `this.PublishRebindMessage()` when name shadowing requires qualification. It preserves comments and trivia from the replaced receiver, type arguments, and argument list, and rechecks that the helper and replacement still bind correctly.

Fix All is supported for a document, project, or solution. Action availability depends on the IDE's Roslyn integration.
