# BND001: ViewModel の型名の末尾には "ViewModel" と省略可能なASCII数字が必要です

[English](BND001.md) | 日本語

| 項目 | 内容 |

## メッセージ

> 型 '{0}' に [ViewModel] が付与されていますが、型名の末尾が "ViewModel" またはその後にASCII数字（0-9）だけを付けた形式ではありません。この ViewModel のソースは生成されません。

`{0}` は属性を付与した型の名前です。

## 原因

`[ViewModel]` を付与したクラス・構造体の名前の末尾が、大文字・小文字の一致する `ViewModel`、またはその後にASCII数字（`0`～`9`）だけを付けた形式ではありません。ジェネレーターはこの最後の `ViewModel` だけを `View` に置換し、数字は維持します。

## 違反例

```csharp
[ViewModel]
public partial class Counter { }
```

## 修正例

型名の末尾を `ViewModel`、またはその後にASCII数字だけを付けた形式にします。

```csharp
[ViewModel]
public partial class CounterViewModel { }
```

この場合、`CounterView` が生成されます。`CounterViewModel2` からは `CounterView2`、`CounterViewModel12` からは `CounterView12` が生成されます。`CounterViewModelExtra`、`CounterViewModel2Extra`、ASCII以外の数字で終わる名前はこの規則に該当しません。改名した型への参照も必要に応じて更新してください。

## 対象範囲とソース生成

属性を付与した型の宣言位置に報告します。その型のViewModelソースとViewソースは、どちらも生成しません。他のViewModelの生成は継続できます。この診断はUsage Analyzerではなく、ソースジェネレーターが報告します。

親型と生成ファイル名については、[生成コードの規則](../../README_JA.md#生成コードの規則)を参照してください。
